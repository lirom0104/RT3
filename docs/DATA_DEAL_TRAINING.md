# DATA-DEAL: shared and thermal-only LoRA

> 当前结果已按类型和模型整理：共享版位于 `outputs/depth_pointcloud/data_deal_shared/`，仅红外版位于 `outputs/depth_pointcloud/data_deal_ir_only/`；高斯渲染位于 `outputs/novel_views/data_deal_shared/ThermalGaussian/Ebike/gaussian_render/`。完整导航见 [outputs/README.md](../outputs/README.md)，历史路径对照见 [PATH_MAPPING.csv](../outputs/PATH_MAPPING.csv)。原始 artifacts 配置与校验记录保留原路径；下文启动记录描述原实验，重新生成结果时应使用新的运行记录目录。

Both experiments start from the frozen official DA3-GIANT-1.1 checkpoint with
fresh LoRA weights and thermal camera tokens. DATA-DEAL supplies the depth pseudo
labels generated by DA3NESTED-GIANT-LARGE-1.1 and the accompanying camera labels.

| Experiment | LoRA scope | Config | GPU | Checkpoint directory |
| --- | --- | --- | --- | --- |
| Shared | RGB and thermal tokens | `configs/thermal_giant_data_deal.json` | 0 | `checkpoints/thermal_giant_data_deal/` |
| Thermal-only | Thermal tokens | `configs/thermal_giant_data_deal_ir_only.json` | 0 | `checkpoints/thermal_giant_data_deal_ir_only/` |

Both experiments now run sequentially on physical GPU 0: shared first, then
thermal-only. The thermal-only run originally started on GPU 1; it is paused
after a complete checkpoint and will resume on GPU 0 with its saved optimizer,
scheduler, early-stopping counter, and sampler position. GPU 1 is released.
Each run needs about 18 GB of GPU memory, so they are scheduled one at a time.

The only config differences are `lora_scope`, `output`, and `checkpoint_dir`.
Both use seed 0, 8 views at 392x518, one GPU, accumulation 2, AdamW at 5e-5,
10% warmup, LoRA rank 64/alpha 128/dropout 0.1, and blocks 13 through 39.
RGB and thermal geometry losses are active in both experiments. Thermal-only
LoRA retains cross-modal attention; mixed-input RGB predictions can change.

The original scene split is preserved: 39 training scenes (4,646 pairs),
12 validation scenes (1,175 pairs), and 9 held-out scenes (945 pairs).
The held-out scenes do not contribute to gradients or checkpoint selection.
The standard loader uses finite positive depth as its validity mask, with the
same resize and crop as the previous baseline. Additional DATA-DEAL confidence
and sky masks are not used by this recipe.

Each epoch has 598 training batches and 299 optimizer updates. After each epoch,
validation runs in RGB, mixed, and thermal modes. The selection score is the
mean of mixed and thermal geometry losses. A strictly lower score resets the
non-improvement counter. Training stops at 100 epochs or after 20 consecutive
epochs without improvement, whichever comes first.

Logs and training records use the matching experiment name under `artifacts/`.
`adapter_best.pt` is the best validation adapter (possibly the initial baseline);
`adapter_last.pt` is the most recent adapter, and `last.pt` includes the optimizer
and scheduler state for resuming this same DATA-DEAL experiment.

Launch from the repository root:

```bash
CUDA_VISIBLE_DEVICES=0 OPENBLAS_NUM_THREADS=4 bash scripts/run_thermal_giant.sh \
  --config configs/thermal_giant_data_deal.json
CUDA_VISIBLE_DEVICES=0 OPENBLAS_NUM_THREADS=4 bash scripts/run_thermal_giant.sh \
  --config configs/thermal_giant_data_deal_ir_only.json
```

For resume, append `--resume checkpoints/<experiment>/last.pt` to the matching
command. Starting a new DATA-DEAL run does not resume an older SEAR optimizer.

The active shared run continues in tmux session `da3-data-deal-shared`.
The waiting queue runs in `da3-data-deal-gpu0-queue` using
`scripts/run_data_deal_gpu0_queue.sh <shared-launcher-pid>`. It resumes thermal-only
after the shared launcher exits successfully. Queue status and logs are in
`artifacts/data_deal_gpu0_queue_state.txt` and
`artifacts/data_deal_gpu0_queue.log`. The thermal-only launcher
`artifacts/thermal_giant_data_deal_ir_only/launch.sh` now selects the UUID of
physical GPU 0 and automatically resumes `checkpoints/thermal_giant_data_deal_ir_only/last.pt`.

## Completed training and paired comparison

The shared run stopped after epoch 32 (9,568 steps); its best adapter is epoch 12
(3,588 steps). The thermal-only run stopped after epoch 47 (14,053 steps); its best
adapter is epoch 27 (8,073 steps). Both reached 20 consecutive validation epochs
without improving their selection score and exited successfully on 2026-10-18.

`scripts/infer_data_deal_comparison.py` uses these two `adapter_best.pt` files to
replay `artifacts/comparison_all_scenes_20261010/run_config.json`. Inference uses
the exact original SEAR image paths, pair indices, and ordering from that record;
the adapters were trained on DATA-DEAL. All 60 scenes use 12 RGB and 12 thermal
images in one joint forward, including for the thermal-only LoRA adapter.
This is a visualization over the original full scene list, not a held-out score.

Outputs, matching the standard files under `outputs/depth_pointcloud/sear_shared`, are:

- `outputs/depth_pointcloud/data_deal_shared/<dataset>/<scene>/`
- `outputs/depth_pointcloud/data_deal_ir_only/<dataset>/<scene>/`

Each scene contains `rgb.ply`, `thermal.ply`, `combined.ply`, `depth.png`, and
12 depth PNGs each in `depth/rgb/` and `depth/thermal/`. The native `saddle_balanced`
reference strategy, processing resolution 518, BF16, seed 20261009, point filters,
and 15,000-point per-view cap match the original comparison. No input depth or
camera labels are supplied; Gaussian rendering and depth refinement are disabled.
Depth color ranges and coordinate scales are determined separately per scene/run.

Run on physical GPU 0:

```bash
bash artifacts/comparison_data_deal_20261018/launch.sh
# Resume an interrupted export:
bash artifacts/comparison_data_deal_20261018/launch.sh --resume
# Verify existing completed exports without running inference:
CUDA_VISIBLE_DEVICES='' OPENBLAS_NUM_THREADS=8 OMP_NUM_THREADS=8 \
  /home/lf/miniconda3/envs/da3/bin/python scripts/infer_data_deal_comparison.py --verify-only
```

The record directory `artifacts/comparison_data_deal_20261018/` contains weight
hashes, source image hashes, code snapshots, raw predictions, logs, per-scene
progress, and final validation. Processed input hashes must match the original
comparison before each new scene is exported. Final validation checks all output
hashes, PNG dimensions, PLY counts and finite coordinates, combined cloud content,
raw prediction hashes, input images, and preservation of the original `new` tree.

## Eight-pair training started 2026-10-20

`configs/thermal_giant_data_deal_paired8.json` starts a separate shared-LoRA run on
physical GPU 0, from official DA3-GIANT-1.1 and fresh adapters. Each training sample
uses eight sampled frame indices and both modalities: eight RGB images followed
by their eight thermal counterparts, with each modality's own recorded geometry.
`views=8` continues to count frame indices, preserving 598 batches and 299 optimizer
updates per epoch. Resolution, accumulation, optimizer, LoRA settings, seed,
100-epoch limit and 20-epoch patience match the original shared experiment.

Validation adds an eight-pair group while retaining RGB, mixed and thermal-only
groups. Best checkpoint selection and early stopping use the paired geometry
loss, matching the intended paired inference input. Existing configurations keep
their original sampling and selection rule. Resume rejects changes in these
sampling or selection settings.

New weights are in `checkpoints/thermal_giant_data_deal_paired8/`; launch records,
logs, preflight checks and source snapshots are in
`artifacts/thermal_giant_data_deal_paired8/`. The background tmux session is
`da3-data-deal-paired8`. Original shared checkpoints are preserved. See the
[run record](../artifacts/thermal_giant_data_deal_paired8/README.md) for commands.
